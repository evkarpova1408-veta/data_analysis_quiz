Викторина по Data Analysis
==========================

Данное приложение запускает простую викторину на 10 вопросов
в браузере без необходимости установки программы

Процесс запуска программы
--------------
1. Открыть папку с проектом
2. Скачать файл index.html
3. Кликнуть по нему два раза
4. Викторина откроется в браузере
Альтернативно: перейти по ссылке https://evkarpova1408-veta.github.io/data_analysis_quiz/

Процесс прохождения викторины
-----------
- По открытию викторины сразу высвечивается первый вопрос
- Под названием викторины есть progress bar с указанием кол-ва
выполненных вопросов
- Выбрать ответ можно кликом по нему
- Сразу же отметится правильность выполнения задания
- В случае неправильного ответа, правильный подсвечивается
- Переход на следующий вопрос происходит автоматически, интервал
до 2 секунд
- По окончанию викторины будет выведено кол-во правильных ответов из всех
- Есть возможность пройти викторину заново
